# Orçamento Fácil

MVP web para profissionais autônomos e pequenas empresas criarem e acompanharem propostas comerciais.

## Funcionalidades atuais

- Dashboard financeiro responsivo
- Indicadores de propostas, aprovações e conversão
- Busca de orçamentos por cliente ou serviço
- Formulário funcional para cadastrar uma nova proposta
- Status de rascunho, enviado e aprovado

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Tecnologias

Next.js, React, TypeScript, Tailwind CSS e Lucide Icons.

Consulte [o roadmap](docs/ROADMAP.md) para acompanhar as próximas etapas.

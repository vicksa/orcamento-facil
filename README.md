# Orçamento Fácil

Aplicação web para profissionais autônomos e pequenas empresas criarem, enviarem e acompanharem propostas e orçamentos de forma simples.

## Problema

Muitos prestadores ainda montam orçamentos manualmente, perdem tempo alterando documentos e não acompanham se o cliente respondeu.

## Solução

O Orçamento Fácil centraliza clientes, serviços e propostas, calcula os valores automaticamente e gera um orçamento profissional pronto para ser enviado.

## MVP

- Cadastro de clientes
- Cadastro de produtos e serviços
- Criação de orçamentos com itens, descontos e validade
- Cálculo automático do valor total
- Geração de PDF
- Status: rascunho, enviado, aprovado, recusado e vencido
- Link público para visualização da proposta
- Painel com propostas recentes e taxa de aprovação

## Próximas funcionalidades
